# Interactive Sales & Revenue Analysis Dashboard

An enterprise-grade business intelligence dashboard built with **Python, Streamlit, Pandas, and Plotly**. This application enables business analysts to ingest raw transaction logs (CSV/Excel) and extract immediate actionable insights regarding core KPIs, revenue trends, and product performance.

## 🚀 Key Features
* **Dynamic File Ingestion:** Supports automated mapping of custom CSV and Excel files.
* **Granular Data Slicing:** Real-time filtering architecture across Regions and Product Categories.
* **Interactive Data Visualization:** Custom line trends and horizontal distribution bar charts via Plotly.
* **Algorithmic KPIs:** Instant calculation of Total Revenue, Units Sold, and Average Order Value (AOV).
